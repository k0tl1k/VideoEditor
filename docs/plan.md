# Дипломный проект: Видеоредактор (C# + WPF)

## Срок
- Крайний срок сдачи: **16 мая 2026**.
- Дата старта плана: **30 марта 2026**.
- Дата актуализации плана: **7 апреля 2026**.

## Технологический стек
- Язык: `C#`
- UI: `WPF`
- Архитектура: `MVVM + слоистая структура`
- Обработка видео: `FFmpeg` (через запуск процессов/обвязку)

## MVP (обязательный минимум)
1. Обрезка видео.
2. Перемещение элементов на таймлайне.
3. Воспроизведение видео.
4. Импорт и экспорт видео.

## Текущее состояние реализации

### Что уже сделано
- Сформирована слоистая структура решения:
  - `VideoEditor.UI`
  - `VideoEditor.Application`
  - `VideoEditor.Domain`
  - `VideoEditor.Infrastructure`
- Все проекты подключены в `VideoEditor.slnx`.
- Реализованы доменные модели:
  - `VideoProject`, `TimelineTrack`, `TimelineClip`, `MediaAsset`, `MediaType`.
- Поднят UI-каркас окна редактора:
  - верхняя панель, панель проекта, монитор предпросмотра, инспектор, таймлайн.
- Добавлен DI-контейнер и композиция зависимостей:
  - `SimpleServiceCollection` / `SimpleServiceProvider`
  - регистрация сервисов `Application` и `Infrastructure`
  - создание `MainWindow` и `MainWindowViewModel` через DI.
- Добавлены базовые сервисы:
  - `IProjectBootstrapService` + `ProjectBootstrapService`
  - `IProjectPathService` + `FileSystemProjectPathService`.

### Что ещё не реализовано
- Реальный импорт медиафайлов.
- Воспроизведение видео в `ProgramMonitor`.
- Отображение и перемещение реальных клипов на таймлайне.
- Trim (обрезка начала/конца клипа).
- Экспорт финального видео через FFmpeg.
