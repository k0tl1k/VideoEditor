# Правила для Codex

## XML-комментарии в C#

1. Внутри тега `<summary>` использовать ровно **1 таб** перед текстом комментария.
2. Текст комментариев должен **заканчиваться точкой**.
3. Для тегов с параметрами и возвращаемым значением использовать формат с пробелами внутри:
   - `<param name="..."> Текст. </param>`
   - `<returns> Текст. </returns>`

### Стиль информации

4. Информация должна быть **краткой и понятной**.
5. Не нужно писать слишком много текста без необходимости.

## Оформление кода в C#

1. Если у `if` внутри только **одно действие**, фигурные скобки `{}` не использовать.
2. Если внутри `if` больше одного действия, фигурные скобки `{}` обязательны.
3. Для `if` с `else` сохранять оформление, которое делает ветвление читаемым и однозначным.
