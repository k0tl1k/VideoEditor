# Дипломный проект: Видеоредактор (C# + WPF)

## Срок
- Крайний срок сдачи: **16 мая 2026**.
- Дата старта плана: **30 марта 2026**.
- Дата актуализации плана: **12 апреля 2026**.

## Технологический стек
- Язык: `C#`
- UI: `WPF`
- Архитектура: `MVVM + слоистая структура`
- Обработка видео: `FFmpeg` (через запуск процессов/обвязку)
- Текущий предпросмотр: WPF `MediaElement` для базового playback внутри приложения.

## MVP (обязательный минимум)
1. Обрезка видео.
2. Перемещение элементов на таймлайне.
3. Воспроизведение видео.
4. Импорт и экспорт видео.

## Текущее состояние реализации

### Что уже сделано
- Сформирована слоистая структура решения:
  - `VideoEditor.UI`
  - `VideoEditor.Application`
  - `VideoEditor.Domain`
  - `VideoEditor.Infrastructure`
- Все проекты подключены в `VideoEditor.slnx`.
- Реализованы доменные модели:
  - `VideoProject`, `TimelineTrack`, `TimelineClip`, `MediaAsset`, `MediaType`.
- Поднят UI-каркас окна редактора:
  - верхняя панель, панель проекта, монитор предпросмотра, инспектор, таймлайн.
- Добавлен DI-контейнер и композиция зависимостей:
  - `SimpleServiceCollection` / `SimpleServiceProvider`
  - регистрация сервисов `Application` и `Infrastructure`
  - создание `MainWindow` и `MainWindowViewModel` через DI.
- Добавлены базовые сервисы:
  - `IProjectBootstrapService` + `ProjectBootstrapService`
  - `IProjectPathService` + `FileSystemProjectPathService`
  - `IMediaImportService` + `MediaImportService`
  - `IMediaDurationService` + `MediaDurationService`
  - `IMediaThumbnailService` + `MediaThumbnailService`.
- Реализован базовый импорт медиафайлов:
  - выбор нескольких файлов через `OpenFileDialog`
  - поддержка видео, аудио и изображений по расширению
  - добавление импортированных файлов в доменную модель проекта
  - защита от повторного добавления одного и того же файла.
- Реализована панель проекта для импортированных файлов:
  - список импортированных медиа
  - отображение имени и типа файла
  - миниатюры для изображений и видео, если их удалось получить.
- Реализована базовая работа таймлайна:
  - отображение видео- и аудиодорожек
  - вставка импортированного медиа на таймлайн
  - автоматическая вставка новых клипов в конец дорожки
  - визуальная отрисовка клипов на основе доменных моделей
  - drag-and-drop перемещение клипов по таймлайну
  - синхронное смещение связанного аудио/видео клипа по `LinkedGroupId`
  - масштабирование таймлайна и линейка времени.
- Реализован базовый `ProgramMonitor`:
  - воспроизведение дорожки таймлайна с `00:00`
  - переход между клипами по их позиции на таймлайне
  - отображение чёрного экрана на пустых участках между клипами
  - отображение изображений как статичных клипов
  - команды `Play`, `Pause`, `Stop`
  - отображение текущей позиции воспроизведения на таймлайне.
- Текущая сборка UI-проекта проходит командой:
  - `dotnet build src/VideoEditor.UI/VideoEditor.UI.csproj -m:1 --no-restore`.

### Что ещё не реализовано
- Запуск воспроизведения с произвольной позиции таймлайна.
- Полноценный микс нескольких дорожек и одновременное воспроизведение нескольких слоёв.
- Опционально: настройка положения, масштаба и наложения видео/изображений в кадре.
- Trim (обрезка начала/конца клипа) через UI.
- Split (разрезание клипа).
- Экспорт финального видео через FFmpeg.
- Сохранение и загрузка проекта с диска.
- Полная обработка ошибок и пользовательские сообщения для импорта/проигрывания/экспорта.
- Полировка кодировки XML-комментариев в части файлов, где текст отображается некорректно.
