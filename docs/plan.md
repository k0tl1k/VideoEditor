## Технологический стек
- Язык: `C#`
- UI: `WPF`
- Обработка видео: `FFmpeg` (через запуск процессов/обвязку)

## MVP (основа проекта)
Это обязательный функционал, который должен быть реализован в первую очередь:
1. Обрезка видео.
2. Перемещение элементов на таймлайне.
3. Воспроизведение видео.
4. Импорт и экспорт видео.

## Что делаем прямо сейчас (Этап 1)

### 1. Фиксация требований (готово)
- Основа MVP утверждена (4 функции выше).

### 2. Базовое проектирование архитектуры (предложение)
Так как раньше не было опыта с WPF, берём простой и безопасный вариант: `MVVM + слоистая структура`.

Рекомендуемые слои:
- `VideoEditor.UI`  
  Окна, XAML, элементы интерфейса.
- `VideoEditor.Application`  
  Сценарии приложения: импорт, воспроизведение, обрезка, экспорт.
- `VideoEditor.Domain`  
  Модели: `Project`, `TimelineTrack`, `TimelineClip`.
- `VideoEditor.Infrastructure`  
  Работа с FFmpeg, файловой системой, сериализацией.

Принцип:
- `View` <-> `ViewModel` (команды и биндинги).
- `ViewModel` вызывает сервисы из `Application`.
- `Application` использует `Infrastructure` для работы с FFmpeg/файлами.

### 3. Минимальная структура экрана
- Левая панель: импортированные файлы.
- Центральная область: предпросмотр/плеер.
- Нижняя область: таймлайн.
- Верхняя панель: кнопки `Import`, `Play/Pause`, `Trim`, `Export`.
