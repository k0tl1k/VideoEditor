# Дипломный проект: Видеоредактор (C# + WPF)

## Срок
- Крайний срок сдачи: **16 мая 2026**.
- Дата старта плана: **30 марта 2026**.
- Дата актуализации плана: **12 апреля 2026**.

## Технологический стек
- Язык: `C#`
- UI: `WPF`
- Архитектура: `MVVM + слоистая структура`
- Обработка видео: `FFmpeg` (через запуск процессов/обвязку)
- Текущий предпросмотр: WPF `MediaElement` для базового playback внутри приложения.

## MVP (обязательный минимум)
1. Обрезка видео.
2. Перемещение элементов на таймлайне.
3. Воспроизведение видео.
4. Импорт и экспорт видео.

  - drag-and-drop перенос медиа-карточек на таймлайн

  - отображение видео- и аудиодорожек
  - вставка импортированного медиа на таймлайн
  - автоматическая вставка новых клипов в конец дорожки
  - визуальная отрисовка клипов на основе доменных моделей
  - drag-and-drop перемещение клипов по таймлайну
  - синхронное смещение связанного аудио/видео клипа по `LinkedGroupId`
  - масштабирование таймлайна и линейка времени
  - визуальное выделение выбранного клипа
  - снятие выбора через кнопку в инспекторе или клик по пустой области дорожки
  - статичная левая панель дорожек с общей вертикальной прокруткой, чтобы названия дорожек и клипы не рассинхронизировались.

  - нижний горизонтальный скролл таймлайна вынесен отдельно и стилизован
  - кнопки дорожек `Show/Hide` и `Mute/Sound` отображаются иконками
- Реализован базовый `ProgramMonitor`:
  - воспроизведение дорожки таймлайна с `00:00`
  - запуск воспроизведения и предпросмотра с произвольной позиции таймлайна
  - переход между клипами по их позиции на таймлайне
  - отображение чёрного экрана на пустых участках между клипами
  - отображение изображений как статичных клипов
  - отображение видео/изображений внутри виртуального кадра 1920x1080
  - базовая настройка положения и масштаба визуального клипа в инспекторе
  - предпросмотр нескольких визуальных дорожек с наложением изображений/видео поверх базового клипа
  - включение/скрытие видеодорожек и mute аудиодорожек
  - громкость аудиоклипа в инспекторе
  - более мягкая синхронизация предпросмотра при перемещении клипа во время воспроизведения
  - команды `Play`, `Pause`, `Stop`
  - отображение текущей позиции воспроизведения на таймлайне.
  - отдельный icon-only toolbar в плеере и таймлайне

  - экспорт вынесен в отдельное окно;

  - добавлена информация о версии через свойства проекта и окно `About`.

### Что ещё не реализовано
- Полноценный аудиомикс нескольких аудиодорожек.
- Полная проверка экспорта на реальных файлах на всех сценариях и форматах контейнера.
- Trim (обрезка начала/конца клипа) через UI.
- Split (разрезание клипа).
- Сохранение и загрузка проекта с диска.
- Полная обработка ошибок и пользовательские сообщения для импорта/проигрывания/экспорта.
- Полировка кодировки XML-комментариев в части файлов, где текст отображается некорректно.
