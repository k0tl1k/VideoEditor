# Icons drop folder

Put your replacement UI icons here.

Recommended filenames:
- `app-logo.png` - app mark for the top bar and window branding
- `import.png` - import/add media action
- `export.png` - export action
- `undo.png` - undo action
- `redo.png` - redo action
- `trash.png` - delete action
- `search.png` - search icon for the Project panel
- `folder.png` - project/media browser icon
- `video.png` - video media type badge
- `audio.png` - audio media type badge
- `image.png` - image media type badge
- `play.png` - play button/icon
- `pause.png` - pause button/icon
- `stop.png` - stop button/icon
- `zoom-in.png` - zoom in control
- `zoom-out.png` - zoom out control
- `show.png` - show video track
- `hide.png` - hide video track
- `mute.png` - mute audio track
- `sound.png` - unmute audio track
- `split.png` - split clip action
- `trim.png` - trim action
- `timeline-handle.png` - optional handle for drag/resizing UI

Notes:
- PNG or SVG both work well.
- Use transparent background for icons if possible.
- Keep sizes square where you can, ideally 16x16, 20x20, 24x24, or 32x32.
- If you use larger source artwork, I can scale it down in the UI.
